# Banking Management System (Java JSP + Servlets + JDBC + MySQL)

## Overview

A web-based Banking Management System developed using Java, JSP, Servlets and MySQL following MVC layered architecture.

The system supports user authentication, account management, beneficiary handling, transaction tracking and admin operations.

## Tech Stack

Java (Core Java)
JSP
Servlets
JDBC
MySQL
Bootstrap
MVC Architecture
DAO Pattern

## Features

User Registration & Login

Create Account

Add Beneficiary

Transfer Money

View Transaction History

Passbook View

Admin Dashboard

Approve Accounts

Manage Users

Session Handling

Input Validation

Exception Handling

## Architecture

MVC Architecture

Controller Layer → Servlets

Service Layer → Business Logic

DAO Layer → Database Access

Model Layer → Entities

View Layer → JSP Pages
